# Backlog inicial — Revysa

Este backlog deve ser reproduzido em um GitHub Project do repositório, com os itens priorizados e estimados.

| ID | Prioridade | Estimativa | História de usuário |
|---|---|---:|---|
| REV-01 | P1 | 2 | Como estudante, quero visualizar minha próxima ação de estudo para saber por onde começar. |
| REV-02 | P1 | 3 | Como estudante, quero acessar materiais organizados por disciplina para encontrar o conteúdo desejado. |
| REV-03 | P1 | 5 | Como estudante, quero ler um capítulo estruturado para estudar de forma ativa. |
| REV-04 | P1 | 5 | Como estudante, quero criar flashcards vinculados ao conteúdo para revisar conceitos. |
| REV-05 | P2 | 3 | Como estudante, quero acompanhar meu progresso de leitura para continuar de onde parei. |
| REV-06 | P2 | 3 | Como estudante, quero visualizar as revisões pendentes para priorizar meus estudos. |
| REV-07 | P3 | 5 | Como estudante, quero perguntar sobre um trecho para compreender melhor o conteúdo. |

As estimativas usam pontos relativos. REV-01 a REV-04 são o núcleo inicial do produto; REV-05 e REV-06 sustentam retenção; REV-07 é uma extensão e não deve bloquear o MVP.
